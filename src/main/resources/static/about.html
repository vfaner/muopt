软件使用说明
1. 配置数据源：点击「数据源配置」，添加你的数据库连接，支持 MySQL/Oracle/PostgreSQL/信创数据库等
2. SQL 优化：进入「手工优化」或「扫描优化」，粘贴 SQL，一键获取索引建议与优化改写
3. 执行计划分析：进入「SQL执行计划」，查看数据库执行计划，优化查询性能
